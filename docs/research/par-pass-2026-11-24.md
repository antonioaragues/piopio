# Real-use pass: PAR2–PAR5 and PAR8 (2026-11-24)

The launch scope (launch plan §3) lists PAR2–PAR5 and PAR8 as built, and "what works, works robustly" asks for real use.
This is the first pass with real models. It used a test instance of the Debug app with its own data folder
(`settings.json` and the model list copied, the key from the Keychain through the app), driven over the engine's socket.
The app served the browser and the key. Nobody clicked the UI, so the drawer, the Review panel and the cards' look
are **not** covered here.

**The fixture:** `par-shop`, a page served by `node server.mjs` that asks for `/api/items` where the server serves
`/api/products` (a 404, then a JSON error in the console), and two strict TypeScript files (`src/cart.ts`,
`src/checkout.ts`) with a `typecheck` script. A git repository, added as a new project: untrusted, network filtered,
Auto-edit, the check detected as `npm run typecheck`.

## Findings

**Fixed in this change**
- **F1, F2 · Browser calls made together raced.** pi runs a message's tool calls in parallel. `browser_open` beside
  `browser_console` answered "The project preview isn't open" (the read ran in 56 ms, the open took 2.4 s); after an edit,
  `browser_open` + reads returned the old page's 404 and error, so the model reloaded with `browser_eval` (an
  approval). Now the browser tools are `executionMode: "sequential"` (pi's own: one such call makes its round run in
  order), and `browserCaller` queues one conversation's calls, which also covers Claude Code, Codex and Antigravity over
  MCP. Test: `background.test.ts` "browser calls made together run one at a time".
- **F5, F6 · Codex's calls to Piopio's tools asked, as empty "Run a command" cards.** Codex 0.170 with codex-acp 2.7
  sends an MCP call as kind `execute`, `rawInput: { server: "piopio", tool, arguments, command }`, and its permission
  request names only the call id. `execute` is never one of Piopio's tools by title (a guard against commands named like
  one), so each call became `bash`, asked with no detail, and its card read `mcp.piopio.browser_open`. Now that structure
  is a match, and a request that names only the call shows it as Piopio already has it. The fake agent's Codex mode
  sends the real shape.
- **F8 · Antigravity's calls to Piopio's tools asked, with empty cards named "Run".** Antigravity CLI 1.5 titles them
  "Run mcp_piopio_browser_open" and adds `toolSummary` to the arguments. Now the prefix is dropped before matching and
  `toolSummary` is left out; the card gets Piopio's own answer (Antigravity reports none). The fake agent's Antigravity
  mode does the same.

**Fixed after the pass (the same day, with the user's go-ahead on F3)**
- **F3 · Diagnostics missed a break in a file the agent didn't edit** (05 DG3). The check kept only lines naming files
  the agent changed, on the reasoning that errors elsewhere were there before. A change to `total()`'s return type broke
  `checkout.ts`, and nothing came back. Now the check runs once before a message's first edit as a baseline, and a
  problem elsewhere counts when the baseline didn't have it (same file and message, any line). A check slower than 20 s
  skips the baseline. Tests: `diagnostics.test.ts`; run 3b above.
- **F4 · A server a coding agent started wasn't "the session's own".** Its background commands aren't in Piopio's
  process list, so its `localhost` asked once per session. Now a port counts when a process under the engine (the
  agents' CLIs are its children) listens on it from the session's folder (`ports.ts`). A server you start in Terminal
  still asks. Test: `ports.test.ts`; runs 8b and 9c.
- **F7 · A coding agent's long-running command ended as an error card.** A tool still open when the agent's turn ends
  was closed as failed with no output. Now a command ends as done, with what it printed and "Still running in <agent>
  when its turn ended"; a turn you stop still fails it. Codex's first try in its own sandbox (`listen EPERM`,
  workspace-write has no network) is a real failure and stays one. Test: `acp-agents.test.ts`; run 9c.

**Open**
- **Small:** in Auto-edit, read-only commands (`ls`, `cat`, `git status`, `curl localhost`) ask on Piopio's agent and
  Antigravity, while Codex runs them in its own sandbox. A passing check says nothing anywhere, so the agent wrote "I
  didn't run the typecheck" right after Piopio's check passed. `process_output` counts the first lines `bash` returned
  as read ("nothing new").

**Not covered:** the app's UI (drawer tabs, Preview from the drawer, the Review panel, approval cards as drawn), a
review of a pull request (the fixture has no GitHub remote), RV4, large repositories, other models.
