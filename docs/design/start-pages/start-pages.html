Start pages: each + opens its own page

Press + next to Chats, Notebooks or Agents in the sidebar and the main window shows a start page made for that kind of thing, the way a new conversation starts in ChatGPT or Claude. It has a heading, the composer, and only the options that kind needs. No sheets, and nothing is created until you start.

Chats +The chat page. A debate starts from here too, because debates are listed under Chats. Notebooks +The notebook page: name, first note, instructions, chats to bring in. Agents +The agent page: name and avatar, a template, an optional first message. Projects +Unchanged. It opens the folder picker, because adding a project means choosing a folder.
Try itClick a + in the sidebar. On the chat page, “Start a debate” turns it into a debate and keeps your text.

Chat

A heading and the composer. The chat is created with the first message, so the sidebar no longer fills with empty “New chat” rows.

Debate

The goal is the message, the criteria are a second line in the box, and the setup is one sentence of selectors with the cost beside it. Reached from the chat page, not from its own +.

Notebook

The name is the heading, typed in place. The box takes an optional first note for Main. Instructions fold away, and recent chats can come in as topics.

Agent

Avatar and name as the heading, then the templates as plain rows. An optional first message is sent once the agent exists, so you can tell it what you want straight away.

How it behaves

  1. Each + opens its own page. Chats, Notebooks and Agents each have a start page. Projects + still opens the folder picker.
  2. Nothing exists until you start. The item is created when you send, press Start or press Create. Leaving an untouched page leaves nothing behind.
  3. Debate lives under Chats. “Start a debate” on the chat page turns it into the debate page and keeps your text as the goal. “Just chat instead” goes back. /debate in the chat box, ⌥⌘N and the compose menu open the debate page directly.
  4. Drafts survive. Leave a page with something typed and a grey “draft” row stays in that section, named with what you typed (“Kitchen renovation”). Clicking it, or the same + again, reopens the page with your text. A second + never makes a second draft.
  5. It starts in place. On start, the composer moves to the bottom, your message appears, and the draft row becomes the real one. A debate opens with the “writes · reviews · rounds” line, a notebook on Main, an agent on its conversation.
  6. The other ways in open the same pages. ⌘N opens the chat page and ⌘⇧N the notebook page. The compose menu, ⌘K, the File menu and the first-run screens do the same. “Move to notebook” on a chat opens the notebook page with that chat ticked.
  7. Errors stay on the page. A line under the box says what happened, that nothing was created, and offers Retry. Your text is kept.
  8. Creating is a page, editing is a sheet. Notebook settings, commit, restore and the trace viewer stay as sheets, because they change something that already exists.

What changes in the code

  • SidebarItem gets .start(kind) for chat, debate, notebook and agent. RootView shows a StartView for it: one shared layout (heading, hint, composer, what goes below), with a part for each kind.
  • The Chats, Notebooks and Agents + in MainSidebar, and the compose menu, set the selection instead of posting notifications that open sheets.
  • newChat() stops calling createThread() up front. The chat page reuses AskBox's send path, which already creates the thread on send.
  • What NewDebateSheet, NewSpaceSheet and NewAgentSheet do moves into their pages (defaults, the maker hint, the estimate, ThreadPicker, templates). The three sheets and their .sheet modifiers go away.
  • Drafts use DraftStore under start:<kind>, as Home does with home. The sidebar shows a draft row when one has text.
  • Docs: spec 16 (the “start sheet” becomes a start page), 04, 06 and 08, and the deliberate differences in docs/design/grey/IMPLEMENTATION.md. New captures of the four pages.

Later, with the same pattern: a new session page inside a project (branch, mode and model as composer selectors instead of NewSessionSheet).

Decisions for you

1. How do you get to a debate from the sidebar?Decided: a link on the chat page. Chats + stays one click.
2. Should the notebook and agent name come first, or come from the first message?Decided: name required, as today. Create stays off until there is a name. Naming them automatically can come later.
