Top-right "+ Add …" in the same place on every page. Adding happens in a sheet that tests things before saving.

List rows show status and a count, then ›. Edit, permissions and Remove live on the detail page.
04 · Footnotes go
The fine print ("codemode", "terminal-UI parts") moves next to the control it affects, or into the detail page.
