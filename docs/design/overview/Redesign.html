Overview: redesign options

Three directions for each tab of Overview (spec 34). The built page follows grey ink to the letter: one ink, hairlines, everything said in words. Here every option keeps Piopio's surfaces, type and tokens but lets numbers lead and color carry data, so the page reads in a glance instead of a paragraph.

Made-up numbers that add up. Colors: one validated data palette (blue, aqua, violet, yellow, pink; checked for color blindness in light and dark), Home's status tones kept for state only (orange asks first, red failed, green ready), and yolk for Piopio's own moments. Hover the charts.

What every option changes

  • Color carries data, never chrome. A validated five-color palette for categories (same hue = same thing across Spend and Activity), one blue scale for amounts, Home's status tones for state. Text stays in ink; a color always has its label next to it.
  • Numbers lead, words follow. Explanations move into ⓘ tooltips; a section says at most one sentence.
  • Piopio's voice in one place per page (yolk + the chick): Cheaper next time on Spend, the busiest day on Activity. Never more.
  • Grey ink stays for the rest of the app. This loosens it for Overview only, as Home did.
  • Mixing is fine: e.g. Spend A + Setup A + Activity A is the calmest set; B·B·B the warmest; C·C·C the most analytical.
