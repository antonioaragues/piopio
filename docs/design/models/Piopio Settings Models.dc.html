What's wrong today

The split
Models page: connected providers, things detected on the Mac, and which model each mode uses. Add provider sheet: the catalog of 40+ providers and custom endpoints.
Custom is first-class
Base URL, API format, optional key and headers. Piopio tests the endpoint as you type and lists the models it finds before you save.
