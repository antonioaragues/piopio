# Adding a project

`proposals.html` holds three mockups (2026-11-15). The user picked **A**: the Projects + opens a menu (New Project,
Open Folder…, folders on this Mac), and a new project is named in place in the sidebar. Decisions in
[spec 18 §17](../../spec/18-conversation-first.md) (CF14–CF16). `app/` holds captures with the scripted model: the
empty name row (`naming.png`) and the project's first page after Return (`made.png`).

Different from the mockup:
- The row starts empty with a "Project name" placeholder, not a selected default name.
- The first page offers only "Write them" (the project's Settings). "Let the first conversation draft them" needs the
  engine to draft AGENTS.md from a message, which isn't built.
- The native menu can't be captured by the window snapshot, so there's no capture of it.
