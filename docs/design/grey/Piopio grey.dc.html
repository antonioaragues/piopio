Quick Chat · ⌥Space
What's the difference between actors and Sendable?
Sendable marks a value as safe to pass between concurrency domains. An actor is a domain: it owns mutable state and serializes access to it.
You send Sendable values into actors; the actor itself is implicitly Sendable.
