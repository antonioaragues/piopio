# Temporary chats

`Options.html` (published as an artifact) holds two rounds, 2026-11-24:

1. Where a temporary chat shows and what you see when you come back to it: A (in Conversations, a strip on top),
   B (a Temporary folder, a card above the composer), C (the chat itself dashed). **The user chose A.**
2. How to turn one on: a corner button, a switch above the box, or the box's + menu. **The user chose none of them
   and went back to round 1's chip in the box, on Home and on the New conversation page.**

As built: [spec 14 §8](../../spec/14-memory.md). Different from the mockup: the sidebar uses SF Symbols' `timer`
instead of a dashed bubble (there's no dashed bubble symbol), and New Temporary Chat is ⌃⌘N (⇧⌘N is New Project).
