Chat / session thread, v3
Fewer controls, calmer type, no interruptions. Back to Piopio v2.
Why the type feels off
Lines run about 1,350 px wide (around 190 characters), so the eye loses its place. Full mono paths break every sentence. Thought, Worked, Checkpoint and Copy are all the same grey size, so nothing leads.
The fix
Reading column capped at 680 px (about 75 characters), prose at 15/1.6, paths shown as short file chips. Activity becomes one quiet line, and message actions appear on hover.
Control count
Toolbar: 7 → 2. Composer: 5 → 3. Checkpoint dividers: one per turn → 0 (now an action on each of your messages).
