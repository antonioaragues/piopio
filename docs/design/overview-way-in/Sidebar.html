The way into Overview

Today Overview opens only from "This Mac · $0.00 today" in the sidebar footer. Every option below takes the cost out of the sidebar: the footer says who you are and where Piopio runs, and money lives only in Overview.

Each window shows Overview open, so you see how the sidebar marks where you are.
