CloudA cloud machine clones antonioaragues/piopio from main, works on piopio/telegram-approvals and opens a PR. Keeps going with your Mac off. About $0.02 an hour of work, plus the model.
CancelStart in cloud
  • Cloud is offered only when the project has a GitHub remote; otherwise the row is grey with "Needs a GitHub repo · Set up".
  • The machine's disk doesn't survive sleep, so everything lives in the branch: "Continue here" fetches it into a separate copy; "Continue in cloud" on a Mac session pushes the work in progress first.
  • The cost line is an estimate from the machine size; the session's inspector footer shows the real one.
