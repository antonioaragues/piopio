# Cloud mockup (2026-11-19)

`Cloud.html` is a review mockup for [spec 30](../../spec/30-cloud-target.md), drawn in the grey style
(docs/design/grey tokens, light and dark). It is a reference, not a handoff: nothing here is built.

- **A** · the composer's location chip (This Mac / Cloud) for a new chat; ☁︎ in the sidebar; the Mac Bridge in the footer.
- **B** · a Build session's "Where should this session work?" with Cloud (from the GitHub repo, a branch, a PR).
- **C** · a cloud agent with the Mac away: capabilities say where they run, a step parked for the Mac.
- **D** · Settings › Cloud: account, Mac Bridge, new agents' default, what runs where, usage this month.
- **E** · a cloud-browser sign-in hand-off and a connector approval in Needs you, and the hand-off in the phone app.
- **F** · the Piopio app on the phone: Home with the Mac off (cloud items live, Mac items read-only), and notifications.
