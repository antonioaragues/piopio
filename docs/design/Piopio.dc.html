What's the difference between actors and Sendable?
Haiku 4.5
Sendable is a promise that a value is safe to pass between concurrency domains. An actor is a domain: it owns mutable state and serializes access to it.
So you send Sendable values into actors; the actor itself is implicitly Sendable because callers can only reach its state through await
